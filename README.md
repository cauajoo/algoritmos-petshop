# PetShop (Python)

> **P1 · 2025.2** · Trabalho final de Algoritmos

Sistema de PetShop em modo texto que simula o gerenciamento de usuários, pets, produtos, serviços,
agendamentos e vendas, com os dados gravados em arquivos de texto.

## Como executar
```bash
python menu_inicial.py
```

## Estrutura
| Caminho | Conteúdo |
|---|---|
| `menu_inicial.py` | Ponto de entrada (menu principal) |
| `modulos/` | Regras de cada parte do sistema (usuários, pets, produtos, serviços, validação, menus) |
| `memoria/` | Arquivos de texto que guardam os dados |
| `versao-av2/` | Primeira versão, entregue na 2ª avaliação (um único arquivo) |

## Conceitos praticados
Estruturas de controle, listas e dicionários, funções, modularização e leitura/escrita de arquivos.
